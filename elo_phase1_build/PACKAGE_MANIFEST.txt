Included:

- Official model downloader
- COCO labels
- Architecture/wiring/research notes

Model binary note:
The official detect.tflite binary is not embedded in this archive because the build environment cannot resolve external download hosts. setup_pi.sh automatically downloads the exact official TensorFlow Lite SSD-MobileNet V1 quantized COCO model into models/detect.tflite on the Raspberry Pi.
